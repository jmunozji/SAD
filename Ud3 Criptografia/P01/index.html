    Práctica 3.1: Cifrado Simétrico con GnuPG (GPG)

    Datos de la Práctica

    • Módulo: Seguridad y Alta Disponibilidad (SAD - 0378)
    • Unidad Didáctica: UD3 - Criptografía y Mecanismos de Certificación Digital
    • Requisitos: Sistema operativo Linux (Ubuntu Desktop / MATE o Debian) con la herramienta gpg (o gpg2) instalada.

    1. Objetivos

    • Comprender de forma práctica el funcionamiento del cifrado simétrico utilizando la herramienta estándar de la línea de comandos GnuPG (gpg).
    • Analizar la utilidad de los diferentes modificadores y opciones de gpg para controlar el algoritmo, el formato de salida y el comportamiento de la herramienta.
    • Diferenciar entre salidas cifradas en formato binario y en formato armadura ASCII (ASCII Armor).
    • Construir una hoja de referencia rápida (Cheatsheet) reutilizable para tareas de administración de sistemas.

    2. Introducción Teórica y Sintaxis Básica

    El cifrado simétrico utiliza la misma clave secreta tanto para cifrar la información como para descifrarla. Cuando utilizamos GnuPG en modo simétrico, la herramienta solicita una contraseña, la procesa mediante un algoritmo de derivación de claves (KDF) y cifra el contenido utilizando un algoritmo de cifrado simétrico simétrico de bloque (por defecto, AES-128 o AES-256 según la versión).

    La sintaxis general del comando gpg es:

    gpg [opciones] [fichero]

    Diferencia entre gpg y gpg2

    En distribuciones Linux actuales, gpg es un enlace simbólico que apunta directamente a GnuPG v2 (gpg2). Puedes comprobar la versión instalada en tu sistema ejecutando gpg --version.

    3. Guía de Experimentación con Modificadores

    Antes de abordar las tareas, analiza y experimenta en tu terminal con los siguientes modificadores clave:

    Modificador Nombre largo Descripción
    -c --symmetric Indica a GPG que debe realizar un cifrado exclusivamente simétrico (basado en contraseña).
    -a --armor Crea la salida en formato texto plano ASCII Armor (Base64 con cabeceras) en lugar del formato binario OpenPGP.
    -o --output <fichero> Especifica el nombre y ruta exacta del fichero de salida generado.
    -d --decrypt Descifra el fichero proporcionado (o muestra el resultado por pantalla si no se indica -o).
    --cipher-algo --cipher-algo <ALGO> Fuerza el uso de un algoritmo de cifrado simétrico concreto (ej. AES256, 3DES, BLOWFISH, CAMELLIA256).
    -q --quiet Suprime mensajes informativos de la terminal durante el proceso.

    Comprobación de algoritmos soportados

    Para ver qué algoritmos de cifrado simétrico soporta tu versión instalada de GPG, ejecuta en la terminal: 

    gpg --version
    Observa el apartado "Algoritmos soportados" al final del texto informativo (sección Cifrado).

    4. Tareas Prácticas a Realizar

    Tarea 1: Descifrado del Reto Inicial

    Descarga el archivo adjunto article.png.gpg, el cual ha sido cifrado de forma simétrica con gpg2 mediante la siguiente clave secreta:

    y[b8n9q1s[
    1. Descarga el archivo article.png.gpg a tu directorio de trabajo.
    2. Ejecuta el comando de descifrado adecuado para obtener la imagen original.
    3. Pregunta de investigación: Si descifras el archivo sin utilizar la opción -o, ¿dónde muestra GPG el contenido descifrado? ¿Qué ocurre cuando el archivo descifrado es un binario (como una imagen PNG)? ¿Cómo debes indicar a GPG que guarde el resultado en un archivo llamado resultado.png?
    4. Comprueba con la orden file resultado.png o abriendo la imagen que el descifrado ha sido correcto.

    Tarea 2: Experimentación con Formatos de Salida (Binario vs ASCII Armor)

    Crea un archivo de texto de prueba llamado mensaje.txt con un texto cualquiera.

    echo "Este es un mensaje confidencial de prueba para la UD3" > mensaje.txt

    Realiza dos pruebas de cifrado simétrico sobre este mismo archivo:

    1. Cifrado A (Modo Binario por defecto): Cifra el archivo mensaje.txt usando únicamente la opción -c. Observa el archivo resultante (mensaje.txt.gpg).
    2. Cifrado B (Modo ASCII Armor): Cifra el archivo mensaje.txt combinando las opciones -c y -a. Observa el archivo resultante (mensaje.txt.asc).

    Análisis de laboratorio:

    • Inspecciona el contenido de ambos archivos con los comandos cat y file: 
      file mensaje.txt.gpg
file mensaje.txt.asc
cat mensaje.txt.asc
    • Responde: ¿Qué diferencias estructurales observas entre ambos formatos? ¿En qué situaciones reales resulta imprescindible utilizar el formato ASCII Armor (opción -a) frente al formato binario?
    • Compara el fichero mensaje.txt.asc con el de tu compañero (suponiendo que los ficheros originales eran idénticos), o bien vuelve a cifrar el fichero original. ¿Son iguales? ¿Por qué o por qué no?

    Tarea 3: Desafío de Intercambio de Archivos Cifrados en el Foro

    1. Selecciona o crea un archivo (una imagen, un PDF o un documento de texto) en tu ordenador.
    2. Cífralo de forma simétrica utilizando un algoritmo robusto (fuerza el uso de AES256) y genera la salida en formato armadura ASCII (.asc).
    3. Accede al foro general de módulo.
    4. Sube tu archivo cifrado en un hilo existente para esta práctica indicando el nombre del compañero o compañera a quien va dirigido.
    5. El reto del canal seguro: Hazle llegar la contraseña de descifrado a tu compañero/a. RESTRICCIÓN: Suponed que estáis cada uno en su casa y el único canal de comunicación disponible es AULES. Debes idear un método para transmitírsela utilizando los recursos del entorno.
    6. Descifrado y respuesta: Descifra el archivo que otro compañero haya publicado para ti en el foro y responde a su mensaje confirmando el contenido descifrado.

    6. Cuestiones de Autoevaluación

    Responde brevemente a las siguientes cuestiones finales en tu memoria de prácticas:

    1. Si enviamos un archivo cifrado simétricamente por correo electrónico, ¿por qué es una mala práctica de seguridad enviar la contraseña de descifrado en el mismo correo o en un correo inmediatamente posterior?
    2. ¿Qué ocurre si al intentar descifrar un archivo introduces una contraseña incorrecta? ¿Qué mensaje muestra GPG?
    3. ¿Cuál es el principal problema de escalabilidad del cifrado simétrico cuando aumenta el número de usuarios que necesitan comunicarse de forma segura entre sí? Cita la fórmula matemática que determina el número de claves necesarias y calcula cuántas claves serían necesarias para que toda la clase pudierais comunicaros de forma segura.
